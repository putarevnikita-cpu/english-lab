English Lab — первая версия PWA.

Запуск локально:
1. Распакуйте архив.
2. В папке english-lab выполните: python -m http.server 8000
3. Откройте http://localhost:8000

Для установки на Android разместите папку на HTTPS-хостинге (например, GitHub Pages), откройте адрес в Chrome и выберите «Установить приложение» или «Добавить на главный экран».

Прогресс хранится в localStorage этого браузера. Делайте резервные копии через раздел «Данные».
Интеграция с ChatGPT работает через ручное копирование запроса и структурированного ответа; API не используется.
Кинораздел содержит ссылки на учебные видео, а не копии материалов.
